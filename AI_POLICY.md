# Using AI to contribute to CraftEngine

You may use AI tools when contributing to CraftEngine. You are responsible for understanding each change you submit, checking that it works, and answering questions during review.

- **Write in your own words.** In issues, describe what you observed and how to reproduce it. In pull requests, explain what you changed and why. Write your own review replies, too. Spelling and translation tools are welcome. If you use machine translation, include your original text beneath the translation.
- **Say how you used AI.** If you used an AI tool while preparing a pull request, name it in the description and say what it helped you do. One sentence is enough.
- **Check the result yourself.** Before opening a pull request, verify the behavior your change affects. Tell reviewers what you tested and what happened. For Minecraft compatibility changes, list the versions you tested and identify any versions you could not verify.
- **Keep the diff focused.** Give each pull request one clear purpose. Read the full diff before submitting and remove unrelated refactors, formatting changes, and generated files.
- **Contribute human-made assets.** Textures, models, images, audio, and video distributed with CraftEngine must be human-made. When contributing someone else's work, credit the creator and make sure you have permission to use it.

Maintainers may request changes or close pull requests that do not follow this policy. Repeated violations may lead to restrictions on contributing. If you are new to an area of the codebase, you are welcome to ask for help.
